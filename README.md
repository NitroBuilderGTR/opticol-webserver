# opticol-webserver
Web Server, based on an old project I made in 2020

## Why did I make this project?
This Project has been in the work on and off since 2020. I started making very barebones / basic web-servers using Node.JS. Every time that I started a website project, I would make a web-server for it about 90% of the time.

But the point of this project was to make an app that can run this web-server with a GUI. This was a task that I have thought of making for years but I never got around to properly finishing the project.
I started around mid 2021 with a project I called "POD WebServer", which was a basic Node.JS console app. For POD, I had planned on making a web-ui that allowed for the webserver to be configured (ports for the server etc).

Opticol was the project that was meant to be the project that would make POD obsolete.

It succeeded without much difficulty.


## How was this made?
One of the major reasons why I started this project was to test how useful AI can be to a developer. Can it help me or does it just do the work for me? Does the AI only give me incorrect responses?

I wanted answers to all of these questions and I indeed got the answers I was looking for.

This project was made over the course of about 3 days with the help of Google Gemini. The reason why I chose this AI specifically was because I used it for very, very, VERY basic help before with web development, and it was useful and helped me with that. Because I was going to make Opticol with Electron.JS, I decided that Google Gemini would probably be a good AI to use for this.

I started the project by just making a basic Electron.JS Project, and got Gemini to help me from there. I gave it the old code for my old POD WebServer project and asked it how I implement it to an Electron.JS project.

I also wanted to make a proper overhaul of POD's backend server logic etc, so it helped me fix that as well. I started by asking Gemini "how can i make a button in an electron app that runs a .js file". I then asked it
how to do things such as "now make a console to output the .js file's output" etc.

I went back and fourth many times with the Gemini to get a working project, but it wasn't all Gemini's work this project. I have spoken to people in the tech industry and they believe that AI should be used and treated as a tool for developers (in this context). They will not replace developers because you still need to know how to use the AI's code that it generates for you. You still need to know how what to ask the AI etc.

This project not only supports this, but overall this project has been fun to work with and has been really interesting for me to see how AI can help developers with bugs etc. It can help with productivity and sometimes even explain why issues have happened and what some things in the code do. It can be really useful.
